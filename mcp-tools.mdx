This page lists every tool the FocusAlpha MCP server (`https://mcp.focusalpha.ai/mcp`) exposes. Each tool is a thin wrapper over one REST endpoint or a small group of them, so the linked page documents its parameters, response fields, coverage and caveats. To connect a client, see [Connect via MCP](/mcp-setup).

<Info>
  Every tool is read-only, available on every plan (except `get_private_company`, which is Fund only), and costs the same credits as the REST call behind it (see [Plans and credits](/concepts/plans-credits)). An agent that is unsure which tool answers a question can call `list_datasets` (free): it returns every dataset, what it answers, its coverage and its known traps.
</Info>

## Pick the right tool

Several datasets sound alike but answer different questions. Use this table before you reach for a tool.

| You want | Use | Not |
| --- | --- | --- |
| What the company itself expects (forward guidance, with the quote) | `get_guidance` | `get_consensus`, `get_research` |
| Whether the company raised or cut its guidance | `get_guidance_changes` | `get_guidance` |
| What analysts expect: estimates, surprises, price targets, ratings | `get_consensus` | `get_guidance` |
| Where prediction markets set the EPS bar | `get_prediction_markets_consensus` | `get_consensus` |
| What outside analysts and specialist publications wrote | `get_research` | `retrieve` |
| What management said about a topic, on calls and at conferences | `retrieve` | `get_research` |
| The figures a release printed (non-GAAP metrics, KPIs) | `get_8k_earnings_results`, `get_8k_company_measures` | `retrieve` |
| Audited statement figures | `get_income_statements`, `get_balance_sheets`, `get_cash_flow_statements` | `retrieve` |
| What just happened to a company | `get_company_events` | `get_company_news` |
| Market-moving news that names no company | `get_macro_news` | `get_company_events` |
| Index, commodity and crypto prices | `get_benchmark_prices` | `get_macro_series` |
| Companies that match a condition | `screen_companies` | `search_companies` |
| An ETF (ETFs are not in the company registry) | `search_etfs`, `get_etf` | `search_companies` |
