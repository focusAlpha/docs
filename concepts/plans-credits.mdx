Every FocusAlpha API key belongs to a plan. Every dataset except [private companies](/companies/private-companies)
(Fund only) is available on every plan, including Free — your plan determines how many credits you have to spend and how fast
you can call the API. This page explains both.

## Plans

| | Free trial | Professional | Fund |
|---|---|---|---|
| Credits | 100, one-time | 1,000 per month, per seat | Unlimited |
| Credit renewal | Never — a trial grant | Monthly | Monthly |
| Rate limit | 20 requests/min | 120 requests/min | 600 requests/min |
| Max `top_k` on `/v1/retrieve` | 10 | 25 | 50 |
| How to get it | Sign up at [app.focusalpha.ai](https://app.focusalpha.ai) | Self-serve upgrade in [settings](https://app.focusalpha.ai/settings) | Sales-led — [talk to sales](https://focusalpha.ai/contact) |

The Free plan's 100 credits never expire, but they also never renew — they are a trial
allowance for evaluating the API. Professional and Fund balances reset to their full
grant at the start of each billing period; unused credits do not roll over.

For current pricing, see your [account settings](https://app.focusalpha.ai/settings).

## How credits are metered

Every metered request costs a fixed number of credits for its dataset — never a
function of how many rows it returns. There are three tiers:

| Credits per call | Datasets |
|---|---|
| **0** | Company registry (`GET /v1/companies`, profile, identifiers, listings, corporate events), company calendar (`GET /v1/calendar`), and every discovery / vocabulary endpoint listed below |
| **2** | Semantic retrieval (`POST /v1/retrieve`), full documents (`/v1/documents`), the company, ETF and adviser screeners, 13F institutional holdings, ETF data (`/v1/etfs`), and news |
| **1** | Everything else — financials, filings, events, guidance, transcripts, insider trades, market data, regional filings, macro, and the rest |

Each dataset page states its price in the header line. The same prices apply whether a
call comes from your API key, an MCP client, or the FocusAlpha app: the app's chat
assistant bills every data lookup it makes on your behalf to the same balance at the
same per-call price.

The credit is charged when your request is accepted, before the handler runs. If the
request then fails — a validation error, a missing resource, a server fault — the charge
is **automatically refunded**. You only pay for calls that return answers.

One endpoint goes further: `GET /v1/filings/items` also refunds a successful response
that carries no items (for example, a filing that could not be parsed into items). An
answer-less 200 there costs nothing.

## Free endpoints

Discovery and vocabulary endpoints cost **0 credits**, so you can always enumerate what
is available before spending anything:

| Endpoint | What it lists |
|---|---|
| `GET /v1/filings/tickers` | Tickers with filings coverage |
| `GET /v1/filings/ciks` | CIKs with filings coverage |
| `GET /v1/filings/types` | Supported filing types |
| `GET /v1/filings/items/types` | Item types per filing type |
| `GET /v1/company/facts/tickers` | Tickers with company-facts coverage |
| `GET /v1/company/facts/ciks` | CIKs with company-facts coverage |
| `GET /v1/screen/facets` | Screener filter values and counts |
| `GET /v1/screen/terms` | The product/relation term vocabulary |
| `GET /v1/etfs/taxonomy` | The four-level ETF classification vocabulary |
| `GET /v1/etfs/screen/facets` | ETF screener filter values and counts |
| `GET /v1/institutions/screen/facets` | Adviser screener filter values and counts |
| `GET /v1/news/themes` | News theme vocabulary |
| `GET /v1/8k-events/families` | 8-K event families, fields, and observed values |

Two account endpoints are also free to call:

- `GET /v1/usage` — your request totals for a period, broken down by key
- `GET /v1/_status` — per-dataset coverage and freshness (see [Coverage and freshness](/concepts/coverage))

## Dataset access

Every dataset — including screening, ETF data, live news and events, guidance, regional
filings and the WebSocket event streams — is open to every plan. The one exception is
[private companies](/companies/private-companies), which is Fund only: on Free and Professional it
returns `402` before any credit is spent. Otherwise credits and rate limits
are the only difference between plans, so the Free plan's 100 credits are a way to try
any dataset before you upgrade.

## Buying more credits

Free, Explore and Professional accounts can buy credit packs from
[Settings → Plan → Buy credits](https://app.focusalpha.ai/settings) (a one-time card
payment through Stripe):

| Pack | Price |
|---|---|
| 500 credits | $100 |
| 2,000 credits | $360 |

Purchased credits **never expire** and are spent only after your monthly allowance is
used up, so a pack bought mid-month is still there next month. They show up in your
dashboard as a separate "purchased credits" line under the monthly bar. Fund plans are
unlimited and have nothing to top up.

## When you run out of credits

A metered call with an empty balance (monthly allowance and purchased credits both at
zero) returns `402 Payment Required`:

- On the Free plan the message is `Free credits used up. Upgrade to keep making requests.`
- On a paid plan it tells you that you are out of credits for the current billing period.

Either way, a [credit pack](#buying-more-credits) or an upgrade restores access at once.

See [Errors](/concepts/errors) for the envelope shape.

<Tip>
You will get a heads-up before hitting zero: when a paid balance drops to 10% or less of
its grant, we send one email per billing period to the account owner.
</Tip>

## Checking your consumption

`GET /v1/usage` is free and returns request totals for a date range (defaulting to the
current month), broken down by API key prefix:

```bash
curl "https://api.focusalpha.ai/v1/usage" \
  -H "Authorization: Bearer $FOCUSALPHA_API_KEY"
```

```json
{
  "period": { "from": "2026-08-01T00:00:00.000Z", "to": "2026-08-27T14:00:00.000Z" },
  "totals": { "requests": 412, "chunksReturned": 3180 },
  "byKey": [{ "prefix": "fa_live_7Fb3", "requests": 412 }]
}
```

Your dashboard at [app.focusalpha.ai](https://app.focusalpha.ai) shows the same numbers
alongside your remaining credit balance.
