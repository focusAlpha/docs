Korea DART Report Sections serves individual sections of a Korean company's DART periodic report. Each observation is one row of one section, filed to DART in Korean. Seven sections are available, each at its own route under the company's `kr` path, and every row links back to the original DART document.

<Info>
  **Plan:** Free and above · **Credits:** 1 per call
</Info>

## The Seven Korea Report Sections

Each section has its own page with fields, examples and caveats.

## Kind Is Not Decoration

<Warning>
The forms behind one section have **different reporting rules**, so rows of different kinds are not comparable and must not be summed together.

Filter to one `kind` before aggregating anything. On debt, `kind` matches the row's `debt_type` field. Passing `kind` to a section that has none returns `404`.
</Warning>

## Some Rows Are the Filer's Own Subtotals

<Warning>
Some rows are the filer's **subtotal lines** — named 계, 합계 or 합 계 — rather than individual entries.

Check for them before summing a section, or the total will be counted twice.
</Warning>

## Korea Report Sections Date Convention

`year` applies to every section **except** `ownership`, which is dated rather than annual and takes `date_gte` and `date_lte` instead. The other six sections reject `date_gte` and `date_lte` with `400`.

Rows from the periodic report carry `bsns_year` and `report_period`, which is `annual`, `half`, `q1` or `q3`. There is no `report_period` filter on the section routes, so read it on each row.

## Korea Report Sections Paging

Rows are returned newest filing first. Pass `next_cursor` back as `cursor` to get the next page. Rows of different kinds can share a position inside one filing, so a page boundary can drop rows when you page through several kinds together. Filter to one `kind`, or ask for a `limit` large enough to take the whole table in one page.

## Korea Report Sections Language and Sourcing

Text fields are the filing's own Korean and are not translated.

Every row carries `filing_url`, the original DART document the figure came from. Cite that when quoting a number.

## Korea Report Sections Coverage

<Warning>
Coverage is 2022 onward and is still backfilling, newest year and largest cap first. A missing older year for a small company means **not yet loaded**, not not filed.
</Warning>

## Query Korea Report Sections

Every section route accepts a Korean DART corp code (8 digits), a suffixed ticker such as `005930.KS`, an ISIN or a `company_id` in the path. `cursor` and `limit` (1 to 1000, default 100) work on every section. See each section's page for its full parameter list.
